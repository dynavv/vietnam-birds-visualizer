# Task 1 Brief: Khởi tạo Dự án Vite React TypeScript & Cấu hình Styling

## Yêu cầu
Khởi tạo cấu trúc dự án Vite + React 18 + TypeScript + Tailwind CSS + D3.js + Leaflet tại `/home/dynav/.gemini/antigravity/scratch/vietnam-birds-visualizer/`.

1. `package.json`:
- name: "vietnam-birds-visualizer"
- dependencies: `react`, `react-dom`, `d3`, `leaflet`, `react-leaflet`, `lucide-react`
- devDependencies: `@types/react`, `@types/react-dom`, `@types/d3`, `@types/leaflet`, `vite`, `@vitejs/plugin-react`, `tailwindcss`, `postcss`, `autoprefixer`, `typescript`, `vitest`

2. Cấu hình `vite.config.ts`, `tsconfig.json`, `tailwind.config.js`, `postcss.config.js`.
3. `index.html`:
- Cài đặt Google Fonts: *Playfair Display*, *Cormorant Garamond*, *Inter*.
- Nhúng Leaflet CSS (`https://unpkg.com/leaflet@1.9.4/dist/leaflet.css`).
4. `src/index.css`:
- Thiết lập theme Naturalist Paper: màu nền `#FAF8F5`, font-family tùy chỉnh, scrollbar tinh tế.
5. `src/main.tsx` và `src/App.tsx` tối thiểu để chạy được `npm run build`.
6. Chạy `npm install` (hoặc đảm bảo node_modules sẵn sàng) và kiểm tra `npm run build` thành công.
7. Commit git cho Task 1.
